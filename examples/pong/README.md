# Pong Example
This is a functioning example of how to build pong using the matter plugin for physics and the p5.js plugin for rendering.

[Click here to play](https://l1lith.github.io/Lilis-Game-Engine/examples/pong/)

[The game logic is here](https://github.com/L1lith/Lilis-Game-Engine/blob/master/examples/pong/src/components/Pong.jsx)

Player 1 Controls: W & S

Player 2 Controls: Up Arrow Key, Down Arrow Key
