# Contribution Guidelines

By contributing you agree to the following:
1. Your code will be licensed under this projects [custom ESMIT license](https://github.com/L1lith/Lilis-Game-Engine/blob/master/LICENSE.md), and your contributions must be made in the spirit of the license and it's anti-fascist values.
2. You may not submit code that has been generated by an AI and not reviewed by a human with the appropriate skills to judge it's quality (if you couldn't write the code without an AI you probably can't judge it's quality). Also you must stick to using AIs with open source weights that are as eco-friendly as possible like Deepseek, self-hosted AIs, and others.
